# Student Management System

A web-based Student Management System developed
using Python Flask and MySQL.

## Features
- User Registration
- User Login
- Dashboard
- Add Student
- View Students
- Update Student Details
- Delete Student
- Logout

## Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## Project Structure
- db.py - Flask application and database connection
- templates/ - HTML pages
- static/ - CSS files

## Installation

1. Clone the repository.
2. Install dependencies:
   pip install -r requirements.txt
3. Create the student_management database in MySQL.
4. Configure your MySQL connection in db.py.
5. Run the application:
   python db.py
